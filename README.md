# OFC Fantasy Optimizer — 法的ページ

iOS / Android アプリ **OFC Fantasy Optimizer** のプライバシーポリシーを
GitHub Pages で配信するためだけの公開リポジトリ。

- 公開 URL: <https://andenknt31113.github.io/ofc-fantasy-optimizer-legal/privacy-policy.html>
- アプリのソースコードはここには**含まれない**（本体は別のプライベートリポジトリ）

## なぜ独立したリポジトリなのか

App Review はプライバシーポリシー URL の恒久性を見る。アプリ本体のリポジトリは
プライベートなので GitHub Pages を有効化できず、かといって公開に切り替えると
ソルバーの実装・オープニングブック・課金ロジックまで露出する。
**法的ページだけを載せた公開リポジトリ**が、URL の安定性とソース非公開を
両立する最小の構成。

## 更新するとき

`privacy-policy.html` を直接編集して push すれば、GitHub Pages が数分で反映する。
URL は変えないこと —— アプリ内リンク（`legalLinks.ts`）と
App Store Connect の「プライバシーポリシー URL」の両方が固定で参照している。
